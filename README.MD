# 🌍 Country Finder + Climate

This is an interactive web application that allows you to search for countries around the world and obtain detailed information about them, including geographic data and the current weather in their capital.

## 🚨 WEB LIVE
https://synfiniti.github.io/countriesWorld/

## ✨ Main features

- 🔎 **Search by name**: User can type in a country name to find information.
- 📋 **Smart results filter**:
- If there are **more than 10 countries**, a message appears requesting a more specific search.
- If there are **between 2 and 10 countries**, a list with their **names and flags** is displayed.
- If there is **only 1 country**, the following appears:
- Name
- Flag
- Capital
- Population
- Continent
- Time zone
- 🌡️ Current temperature in your capital
- ☁️ Current weather icon (cloudy, sunny, etc.)

## 🌐 APIs used

- [REST Countries API](https://restcountries.com/v3.1/name/{name}) – Para obtener datos sobre países.
- [OpenWeatherMap API](https://openweathermap.org/current) – Para mostrar el clima actual.

## 🛠️ Technologies

- HTML
- CSS
- JavaScript (Vanilla)

## 🚀 How to use

1. Clone or download the project.
2. Make sure you have an internet connection to access the APIs.
3. Open the `index.html` file in your browser.
4. Type a country name in the search field.
5. View dynamic results as you type.
